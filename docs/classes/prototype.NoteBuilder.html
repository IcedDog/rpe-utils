    Class NoteBuilder

    Fluent wrapper around a single Note.

    Provides property setters that return this for chaining and a .toLine() method to navigate back to the containing line.

    Example

    new NoteBuilder(chart, 0, 0)
      .setX(50)
      .setSpeed(1.5)
      .setTint([255, 128, 0])
      .setAlpha(200);
