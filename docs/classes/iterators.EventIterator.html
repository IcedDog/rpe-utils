    Class EventIterator

    Fluent iterator that filters and transforms events across all lines.

    Example

    eventIterator()
      .onChannels('moveX', 'moveY')
      .between(0, 32)
      .process(ev => { ev.start *= -1; ev.end *= -1; })
      .run(chart);
